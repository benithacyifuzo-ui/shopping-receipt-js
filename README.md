# Smart Shop Receipt Calculator

## Description

This is a simple JavaScript program that calculates supermarket shopping costs, applies discounts, calculates VAT, and generates a shopping receipt.

## Features

- Calculates product prices and subtotal.
- Applies a 10% discount.
- Calculates 18% VAT.
- Displays the final total and customer's change.

## Technologies Used

- JavaScript
- Node.js
- Visual Studio Code

## How to Run

Open the terminal and type:

node shopping-receipt.js
